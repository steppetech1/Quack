# AGENT.md - documentation/

Правила для ИИ-агентов внутри `documentation/`. Читать вместе с корневым `AGENT.md`.

## Что здесь
Проектные документы — источники истины для кода. Это **не** место для заметок агентов и не журнал работы.

| Документ | Обозначение |
| :-- | :-- |
| `Технический_документ_AI_и_архитектура_памяти_1.md` | `Т-§N` — законы ядра, события, память, LLM, очередь |
| `DevOps_развёртывание_и_эксплуатация_1.md` | `Д-§N` — процессы, образы, compose, CI, эксплуатация |
| `Продуктовая_логика_платформы_обучения_1.md` | `П-N` — продуктовая логика; при конфликте с техдоком техрешение неверно |
| `ТЗ Фаза 4 (единое).md` | `Ф4-§N` — **действующее задание** трёх потоков A/B/C |
| `ТЗ Фаза 3 (единое).md` | `Ф3-§N` — история: задание Фазы 3, его реестр закрыт (ТЗ Ф4 §2.4) |

Спецификация Фаз 1–2 (`С-§N`) и ТЗ Фазы 2 в рабочем дереве удалены, но остаются в истории git; `С-§N` —
только описание того, что сейчас лежит в коде, источником требований не является (ТЗ Ф4 §0.1).

## Правила
- **Только чтение по умолчанию.** Не правь эти документы в ходе задачи по коду. Расхождение документа с кодом
  или другим документом — не повод править текст: оформи решение класса B/C в `backend/PHASE4_NOTES.md`
  (ТЗ Ф4 §0.4) и сообщи владельцу.
- Менять документы можно только по прямой просьбе владельца. Для ТЗ Ф4 правки вносит владелец; исполнители
  фиксируют предложения в журнале решений.
- Приоритет источников — ТЗ Ф4 §0.4.1: законы ядра `Т-§1.1` → `Т-§22`, затем контракты `Т-§` → `Д-§` → `П-§` →
  контракты ТЗ Ф4 → код. Реестр осознанных отклонений — ТЗ Ф4 §2.4.
- Метки в документах (ТЗ Ф4 §0.1): **[КОНТРАКТ]** не менять в одностороннем порядке; **[РЕШЕНИЕ Ф4]**
  (и **[РЕШЕНИЕ Ф3]** в истории) исполнять как контракт;
  **[ОРИЕНТИР]** можно менять при соблюдении контрактов; **[ПРОВЕРИТЬ]** не опирайся, пока не подтверждено тестом.
- Ссылайся на разделы так: `Т-§2.3`, `Д-§8.1`, `Ф4-§7.3`, `С-§8.5`.
- Имена файлов с кириллицей и пробелами сохраняй как есть; не переименовывай документы — на них ссылаются
  `backend/CLAUDE.md`, ТЗ и скиллы.
- Не клади в папку секреты, выгрузки логов, бинарные артефакты.
