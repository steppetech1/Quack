# Сворачивание навыков внутри темы

Решение: раздел «Навыки» на странице темы получает заголовок-кнопку со стрелкой, по нажатию список сворачивается и разворачивается. Выбор запоминается в браузере (один на все темы), по умолчанию список раскрыт.

## Что сделано

- `PageSection` (`frontend/components/quack/page-parts.tsx`) получил необязательный параметр `collapse={{ open, onToggle }}`. Без него раздел работает, как раньше (остальные разделы страницы не затронуты). С ним заголовок это настоящая кнопка (`aria-expanded`, `aria-controls`), стрелка поворачивается, тело скрывается атрибутом `hidden`.
- На странице темы (`topic-live.tsx`) раздел навыков использует его; состояние читается из `localStorage` (`quack.topicSkills.open`) при создании и сохраняется при переключении. Чтение защищено `try/catch` (приватное окно, запрет хранилища).
- Счётчик навыков виден и в свёрнутом виде.

## Проверено

Живая страница темы «Projectile motion» (в ней один навык): `aria-expanded` true → после нажатия false и `hidden`; в `localStorage` записано `0`; после перезагрузки страницы раздел остаётся свёрнутым; скриншот: «› § Skills 1» и список скрыт. Типы (`tsc`) и линтер без ошибок.

## Что не делалось

Сворачивание навыков в других местах (граф домена, дерево в боковой панели): там навыки не показываются.
