## Причины

Подтверждены по коду `feat/subject-structure@2fa3d1b`. Подробно — в разделе «1. Проблема» [спеки](../../specs/2026-11-25-structure-building.md).

1. **Пометка `topic` каждого куска становится кандидатом в тему** (`materials/parse.py`, `_subjects`). Любое решение сборщика, кроме «привязать», создаёт тему (`agents/reconcile.py:400-405`). Свободный `topic_hint` сборщика тоже создаёт тему.
2. **Каждое имя из `teaches` и `uses` становится навыком.** `summary` навыка — сырой текст куска, и по нему же считается вектор. Векторы навыков одного куска почти одинаковы.
3. **`REQUIRES` пишется только как «кусок учит X и использует Y»** и только внутри одного вызова `builder`. Листы задач не учат, поэтому связей нет. Между файлами связей не бывает никогда.
4. **Хаб «из материала» создаётся на каждый файл.**
5. **Разметка задач даёт навык только по имени** (`new_skill`), без темы. Задачи семинара видят метку одного навыка (`practice/seminar_tasks.py`, `LabelMap.build(settings, skills=[task.skill_id])`).
