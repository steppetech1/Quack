## Что предлагалось

Два слоя связей:
- **`REQUIRES` навыков** — для модели ученика;
- **хранимые `REQUIRES` тем** — для навигации, без свидетельств.

На графе показывается объединение.

## Почему отвергнуто

- **Это те два расходящихся графа связей, от которых документ уже отказался** (Т-§3.4.5, §4.6).
- **Чтобы это работало, нужны правила чтения и удаления.** Без них удалённая связь возвращается из производной (вывод модели, критик, раздел 3).
- **С центральным навыком отдельный слой не нужен.** Связь тем — это связь их центральных навыков.

## Что могло бы вернуть идею

Если центральный навык окажется непригоден ([H-001](H-001-core-skill-per-topic.md) → `refuted`), связям тем снова понадобится свой носитель. Тогда — с правилами чтения из отчёта критика.
