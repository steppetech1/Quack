# H-NNN: <решение одной фразой>

| | |
|---|---|
| Статус | `proposed` / `accepted` / `in-progress` / `testing` / `confirmed` / `refuted` / `revised` / `rejected` |
| Дата | YYYY-MM-DD |
| Предложил | владелец / ассистент / критик (субагент) |
| Решение владельца | цитата и время, или «принято неявно: …», или «не решено» |
| Наблюдения | ссылки на `observations/...` |
| Спека | ссылка на `specs/...` или «нет» |

## Утверждение

Что мы считаем верным. Одна-три фразы, без «наверное».

## Почему (опыт)

Факты со ссылкой на сырой файл, из которого они получены. Мнение модели — с пометкой «вывод модели».

## Как проверяем

- **Метрика:** что считаем и где берём (запрос, отчёт).
- **Подтверждение:** при каком значении считаем гипотезу верной.
- **Опровержение:** при каком значении отвергаем.
- **Чем можно спутать:** что ещё могло дать такой же результат (смена модели, другой набор файлов, повторная загрузка).

## Стартовые значения

Числа, подобранные без данных, и кто их подобрал. Не договорённости.

## Риски и что известно заранее

Из исследований, отчётов критика, прошлых наблюдений.

## История

- YYYY-MM-DD — статус — на что опирается.
