## Утверждение

После `session.ended` писатель проверяет временные навыки этой сессии.

- **Нет ни одного свидетельства и ни одного показа** — навык сливается в центральный навык своей темы (`skill.merged`), задачи переходят вместе с ним.
- **Темы нет** — навык удаляется из структуры.
- **В отчёт** идёт число таких «пустых» рождений по источникам.

## Почему (опыт)

- **Сейчас разметка задачи создаёт временный навык, даже если ученик не ответил:** 22 из 48 задач с `new_skill` в базе ([raw/16](../observations/2026-11-25-statistics-seminars/raw/16-baseline-first-upload.txt)). Без очистки ТЗ выполняет принцип владельца только наполовину.

## Как проверяем

- **Метрика:** число «пустых» рождений по источникам и доля слитых.
- **Подтверждение:** число навыков на тему после сессий растёт только за счёт навыков с работой.
- **Опровержение:** слияние уничтожает навыки, которые позже оказываются нужны. Тот же навык рождается снова в следующих сессиях — счёт повторных рождений по нормализованному имени.
