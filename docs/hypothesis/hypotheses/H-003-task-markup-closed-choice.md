## Утверждение

Генератор задач, задачи семинара и учитель получают метки всех навыков темы задачи и выбирают из них.

- `new_skill` с полем `reason` — только если ни один навык не подходит.
- Новый навык из разметки задачи сразу получает тему задачи.
- Каждый `new_skill` виден в событиях с источником и причиной, а его судьба у писателя — в отчёте.

## Почему (опыт)

- **22 из 48 задач придумали свой навык** через `new_skill` — база, одна загрузка ([raw/16](../observations/2026-11-25-statistics-seminars/raw/16-baseline-first-upload.txt)). По ученику — 60 из 121 ([raw/06](../observations/2026-11-25-statistics-seminars/raw/06-task-markup-new-skill.txt)).
- **Это 34 отдельных временных навыка в базе** (74 после двух загрузок), сверх 90 из материала ([raw/17](../observations/2026-11-25-statistics-seminars/raw/17-placed-vs-created.txt)). Гигиена раскладывала их по темам.
- **Имена этих навыков** — в [raw/20](../observations/2026-11-25-statistics-seminars/raw/20-new-skill-names.txt).
- **Задача семинара видит метку только одного навыка**: `LabelMap.build(settings, skills=[task.skill_id])` в `practice/seminar_tasks.py` на `feat/subject-structure@2fa3d1b`. Выбирать ей не из чего.

## Как проверяем

- **Метрика:**
  - доля `task.created` с `new_skill` в предмете — запрос `16` из [queries.sql](../observations/2026-11-25-statistics-seminars/raw/queries.sql); запрос `06` считает по всему ученику;
  - распределение `reason`;
  - судьба новых навыков у писателя: слит, оставлен, перенесён (`structure-report`).
- **Подтверждение:**
  - доля `new_skill` заметно ниже базовой (22 из 48, около 46%);
  - выборочная проверка владельцем 20 задач: навык выбран верно.
- **Опровержение:**
  - доля не падает;
  - или выборка показывает, что задачи привязываются к неподходящему навыку темы. Это значит, закрытый выбор заставляет модель ошибаться, вместо того чтобы честно сказать «нет такого навыка».
- **Чем можно спутать.** Если навыков в теме один (центральный, [H-001](H-001-core-skill-per-topic.md)), низкая доля `new_skill` может означать, что всё сваливается в центральный навык. Смотреть вместе с метрикой 1 из H-001.
