## Что предлагалось

Материал даёт только темы и «грани» текстом. Узел навыка появляется, когда его надо измерить или чему-то научить.

## Почему отвергнуто

- **Связи тем выводятся из связей навыков.** У пустой темы связей нет.
- **Критик по коду нашёл, что ломается** (вывод модели):
  - поиск материалов для учителя идёт по `Chunk-[:TEACHES]->Skill`;
  - задачи семинара требуют `skill_id`;
  - готовность темы завышается при одной доказанной грани из пяти;
  - «Сегодня» выбрасывает темы без навыков;
  - косвенные свидетельства не применяются задним числом.
- **Проектор не может вызвать модель**, поэтому «сверка с гранями» на горячем пути — только точное совпадение имени.

## Что взяли

Принцип «остальные навыки — только из работы» остался. Его совместили с центральным навыком, который есть у темы с рождения ([H-001](H-001-core-skill-per-topic.md)): у темы есть узел для связей и состояния, а детализация ленивая.
