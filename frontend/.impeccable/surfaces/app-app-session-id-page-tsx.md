# Сессия

Mode: Operate. Расширение установленного мира (DESIGN.md «Переплёт задачника»), без новой айдентики.

Задача: студент внутри захода читает ход учителя, отвечает на вопрос-предсказание (вариант, уверенность 4 кнопками, «Объясни утке»), видит план и что учитель помнит прошлое. Главное действие — «Ответить» внутри блока вопроса, пока вопрос открыт.

Объём: сценарий «Радиус сходимости» (продолжение «Сегодня № 1»), один скриптованный шаг ответа с разной реакцией на варианты; новая сессия из поля ввода домена с состоянием «учитель думает»; маршрут /session/[id]; формулы — KaTeX. Голос, канвас, свободные ответы учителя — «скоро». Внутренности (токены, модель) не показываем.
