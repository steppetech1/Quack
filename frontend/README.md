# Quack! — frontend

Интерфейс Quack!: лендинг и раздел «Выбор» с чатом, профилем ученика, подборкой и сравнением программ.

## Стек

- [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- React 19, TypeScript
- CSS Modules (без UI-библиотек и Tailwind)
- Шрифты через `next/font/google`: Intel One Mono, Raleway, Inter, Khula, Montserrat Alternates
- Иконки — [Lucide](https://lucide.dev/) (SVG в `public/assets/icon-*.svg`)

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
npm run start    # запуск собранного приложения
```

## Страницы

| Путь | Что там |
|---|---|
| `/` | Лендинг: хэдер, анимированный роадмап, кнопка «Let's go» |
| `/login` | Вход и регистрация по почте и паролю (`?mode=signup` открывает регистрацию, `?next=` — куда вернуться) |
| `/choice` | Приложение: «Выбор», «Обзор» (Quack!), «Подготовка». Открывается только после входа |

Переходы между страницами идут через загрузку с пиксельной уткой.

## Что имитируется и где подключать бэкенд

Сейчас всё работает без сервера:

- **Ассистент** — `src/components/choice/assistant.ts`. Реплики разбираются ключевыми словами, ответы собираются по правилам. Здесь появится вызов API чата.
- **Программы и реалистичность** — `src/components/choice/programs.ts`. Данные вымышленные и помечены в интерфейсе как «демо». Здесь появятся запросы к подборке и датасету.
- **Вход и Google Auth** — `src/components/account/`. Контракт в `contract.ts`, сейчас работает `localAuth.ts`: аккаунты в браузере, пароль хранится как PBKDF2-хэш с солью, вход через Google работает как демо-заглушка с профилем студента. `remoteAuth.ts` говорит с бэкендом (cookie `quack_token`): `/auth/login`, `/auth/me`, `/auth/logout`, `/auth/register`, а также Google OAuth (`GET /auth/google/login` или `POST /auth/google`).
- **Хранение** — `src/components/account/store.ts`, одно место для всего, что помнится об ученике, с разделением по аккаунту (`quack:u:<id>:<ключ>`). Чтение синхронное из кэша, который загружается при входе; запись сразу в кэш и пачкой в хранилище через 250 мс (на сервер — через 1,2 с), остаток уходит при закрытии вкладки. Непрерывные жесты сохраняются только по окончании: граф — когда отпустили или колесо затихло, узлы карты — когда узел отпустили, ширины панелей — в конце перетаскивания. Данные, оставшиеся с времён до входа, забирает себе первый вошедший аккаунт.
- **Переключение на сервер** — `NEXT_PUBLIC_DATA_SOURCE=remote` и `NEXT_PUBLIC_API_URL` (см. `.env.example`). Серверу понадобятся `GET /state`, `PATCH /state` (`{ключ: значение | null}`) и `DELETE /state`; полный список эндпоинтов — в шапке `contract.ts`. Для событий движка Quack! используется `NEXT_PUBLIC_QUACK_SOURCE=remote` (`POST /events`, `GET /sse?topics=quack`).

Функции в `assistant.ts` и `programs.ts` чистые и не зависят от React, поэтому их можно заменить на вызовы API, почти не трогая интерфейс.

## Адаптивность

- больше 1100px — полный вид: левая колонка, чат, «Как я тебя вижу»;
- 761–1100px (в том числе ноутбуки с масштабом 125–175%) — тот же вид с уменьшенным текстом; если панели профиля не хватает места, она открывается поверх чата;
- до 760px — телефон: одна колонка, левая колонка открывается кнопкой в хэдере.


### Windows / Git Bash

Git Bash переписывает значения вида `/api` в путь MSYS (`C:/Program Files/Git/api`). Для сборки прод-варианта
задавайте `MSYS_NO_PATHCONV=1`:

```bash
MSYS_NO_PATHCONV=1 NEXT_PUBLIC_API_URL=/api NEXT_PUBLIC_DATA_SOURCE=remote npm run build
```
