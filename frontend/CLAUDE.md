# Quack!

## О проекте

Quack! — платформа обучения для студентов, в первую очередь точных наук. Это инструмент, а не курс: студент приходит со своим материалом и запросом, система ведёт его и запоминает, где он ошибается и что уже понял.

- Поведение продукта: `docs/product-logic.md`
- Бриф по дизайну: `docs/brief.md`
- Если они расходятся: по внешнему виду прав `brief.md`, по поведению — `product-logic.md`.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Иконки — lucide-react, шрифты — через next/font
- Данные: бэкенд Quack через `lib/api/` при `NEXT_PUBLIC_QUACK_API=1`, иначе моки в `lib/mock/`. Подробно — `BACKEND-COVERAGE.md`

## Язык и тексты

- Два языка: английский (основной, по умолчанию) и русский. Переключение — в «Профиль → Язык» и на вкладке «Язык» в настройках, адреса страниц не меняются, выбор запоминается.
- Переведено всё, включая моки. Новый текст сразу добавлять на обоих языках.
- Русский: обращение на «ты», коротко и живо, без канцелярита. Английский: тот же тон — casual, short, plain words, no corporate speak.
- Без заглушек вроде lorem ipsum: если данных нет — правдоподобные моки по матанализу, линейной алгебре, статистике, базам данных.

## Раскладка (не менять без запроса)

- **Слева — панель доменов.** Клик по домену раскрывает его хабы и загружает в центр граф этого домена вместо текущего. Внизу — «Профиль»: клик открывает меню (Настройки, Использование, Язык, Помощь, Тариф). Настройки — страница в центре со вкладками слева: Общие, Предметы, Skills, Использование, Язык, Данные и аккаунт; панель сессий на ней скрыта.
- **В центре** — вид домена или открытая сессия.
  - Вид домена: название, дедлайн и готовность, переключатель «Граф / Канвасы» (канвасы этого домена), поле «Найти тему»; граф (занимает основное место); под ним строка «Сегодня» — 1–3 компактные карточки-рекомендации; поле ввода внизу.
  - При запуске открыт граф первого домена пользователя.
- **Справа — панель сессий** выбранного домена. Всегда справа, в том числе внутри сессии. Сворачивается в узкую полосу.
- **Первый заход:** графа нет. Пустое состояние — утка, короткий текст и поле ввода.

## Граф домена

- У каждого хаба (главы) — главный нод. Темы хаба соединены цепочкой по пререквизитам («нужно до») внутри хаба; с главным нодом связаны только темы, с которых цепочка начинается.
- Главные ноды хабов стоят по большому кругу, по часовой стрелке по порядку; между последним и первым — разрыв. Цепочка 1–2, 2–3… идёт дугами по кругу (1 и 3 напрямую не связаны).
- Темы хаба — снаружи круга, веером от своего главного нода. Подпись хаба — с внутренней стороны круга.
- Свободная тема (без хаба) — внутри круга, рядом со связанными, соединена только с ними.
- Темы связаны и через границы хабов, связи идут через середину круга: пререквизит из другого хаба — тонкая приглушённая линия; смысловая связь (`related`, без «нужно до») — точечный пунктир.
- Два режима графа: **обзор** (при входе в домен камера показывает 2 хаба, с которыми студент работал последним: они яркие, остальное приглушено; отдалив колесом или кнопкой «Показать весь граф», видно всё; наведение на кластер подсвечивает его), **фокус на хабе** (клик по хабу — камера приближает кластер, он яркий, остальные гаснут).
- Тема — точка с «кольцом памяти»: дуга вокруг показывает, насколько тема держится в памяти. Главный нод хаба — кольцо, дуга = прогресс хаба. Связь — тонкая линия. Никаких карточек и прямоугольников вместо узлов.
- Название хаба видно всегда, крупно и читаемо, подписью у главного нода (номер § — только в фокусе и на странице хаба). Названия тем появляются при приближении.
- Состояния тем: решаешь сам, пора повторить, путаешь, ещё не изучал (контур). Предложенный хаб — полупрозрачный. Тема вне домена — отдельно, с пунктирной связью.
- Зум колесом и кнопками, перетаскивание мышью.
- При наведении на тему — карточка: одно простое предложение о теме (человеческим языком, не определение), состояние словами, активное заблуждение (если есть), кнопки «Изучать», «Практиковать», «Повторять», «История».

## Страницы темы и главы

- Клик по теме открывает страницу темы: сверху короткое описание «о чём тема» (2–3 простых предложения).
- Конспект, шпаргалка (cheat sheet), карточки для повторения и решённые задачи показаны карточками-превью. Клик — карточка анимацией растягивается в окно почти на весь экран поверх всего интерфейса (небольшие поля сверху и по бокам), закрывается крестиком справа сверху и по Esc.

## Канвас

- Канвас — бесконечное полотно как в Miro, на весь экран (боковые панели скрыты, слева сверху «←» назад). Точечная сетка, панорама и зум.
- Слева вертикальная панель инструментов: выделение, рука, перо, маркер, ластик, текст, формула, картинка. На полотне можно рисовать, писать, вставлять картинки и двигать объекты.
- Снизу по центру — чат с учителем по этому канвасу: свёрнут до поля ввода и последнего сообщения, раскрывается вверх.
- Слой учителя (пометки, подсказки) отдельно от слоя ученика и скрывается одной кнопкой.

## Дизайн

- **Тема:** тёмная по умолчанию. Тёплые тёмные фоны, не чисто чёрный.
- **Акцент:** один — оранжевый, слегка приглушённый, не кислотный. Жёлтого нет. Оранжевый — заливка главного действия (одна главная кнопка на экран), кольцо фокуса и короткие метки внимания (дедлайн, текущий шаг, найденное). Подробно — в `DESIGN.md`.
- **Скругления мягкие:** кнопки и поля ~10–12px, карточки ~14–18px, теги — пилюли. Острых углов не делать.
- **Контраст умеренный:** текст не чисто белый, цвета на тон спокойнее «максимально ярких».
- **Утка-маскот** — оригинальный персонаж, не похожий на известных. Не больше одной крупной утки на экран. Места: пустой старт, поле «Объясни утке» в вопросах, статус фоновых агентов («утка готовит демо»), маркер хаба с дедлайном. Тон — ирония для студентов, не детское приложение.
- **Не делать «ИИшный» вид:** градиентные заливки фона, эмодзи вместо иконок, карточки с цветной полосой слева, однотипные сетки одинаковых карточек, glassmorphism, всё по центру.
- **Доступность:** контраст текста не ниже 4.5:1, кликабельные области от 40px, настоящие `button` / `a` / `input`, `aria-label` у кнопок-иконок.

## Референсы

- `references/` — скриншоты, `references/notes.md` — что брать из каждого. Брать только то, что там отмечено.
- LearnHarness (github.com/amosblomqvist/learnharness) — референс раскладки и UX. Лицензия AGPL-3.0: код не копировать, только идеи и паттерны.

## Как работать

- Дизайн — через `/impeccable`: `shape` → вёрстка → `critique` → `polish` / `audit`.
- Перед крупным изменением — короткий план. Вопросы — только если ответ меняет результат.
- Менять только то, что просят. `docs/` и `references/` не трогать без просьбы.
- После изменений интерфейса — проверить в браузере (`npm run dev`) на десктопе и на ширине телефона.
